# PR 1606 visual demonstrations

Captured from The Interceptor commit 0a4f4f1d24333564a1203094c672723a09f72e9d using Chromium and the existing popup switching benchmark fixture.

The isolated local fixture uses synthetic addresses, a fake EIP-6963 wallet, 1,000 ms RPC delay, and 2,000 ms wallet delay. These demonstrate rendered behavior; they are not real-wallet latency measurements. Screenshots capture the top 520 × 340 pixels of the real popup. The GIF assembles captured frames with a pause at completion.

This branch hosts PR media only; these assets are not part of the extension code change.
